Architecture

Three lanes: ui/ sees state, harness/ runs the pipeline, infra/ stands it up. Five figures, one vocabulary; the Mermaid twins and the extension recipes live in the document.

1 · Three lanes, one direction

Apps import packages, packages import core, core imports nothing. Surfaces reach the harness over HTTP; batteries are injected, never imported.

AUTHORED from docs/10-architecture.md §2 and pnpm-workspace.yaml. Mermaid twin §4.1.

2 · One iteration, and the backfeed that closes it

One 3pt loop tick: Plan reads the last checkpoint, Build runs builder ↔ reviewer turns, Instrument measures, rewrites the policy, tags. The next Plan reads the rewrite.

AUTHORED from @3pt/core runIteration and docs/10-architecture.md §4.2. Ran today against the memory store: policy v0 → v1, cp/1.

3 · Batteries, tool grants, stages

Instrument changes what a stage may do by editing policy.toolGrants in Atlas, not stage code. That edit is the Recursive Harnessing proof.

AUTHORED grants from seedPolicy() and harness/policies/v0.json; descriptors in infra/batteries/*/src/index.ts. Mermaid twin §4.3.

4 · What runs where

Nothing stateful lives on a machine. Two machines, one Sandbox cluster: the install-loop demo. The deployed worker runs the same tick as the local one.

AUTHORED hosts from docs/10-architecture.md §4.5 and .env.example. TO CONFIRM worker deploy, inspector Pages project, Sandbox cluster, second-machine install loop: none exist yet.
