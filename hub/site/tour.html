Tour setup what a new user gets, and when

  • The tour starts once, on the first visit. The Tips button starts it again.
  • One tip at a time. Each tip points at one thing on the screen.
  • A tip for a card that is not on screen is skipped. The tour only explains what the user can see.
  • Skip is one tap. Esc closes the tour. Arrow keys move between tips.
  • "How it learns" is for the presenter and the owner. A flag turns it on.
  • Each tip names a region with data-region. The web app, its tests and its screenshots use the same names (ui/apps/web/src/tour.ts).
